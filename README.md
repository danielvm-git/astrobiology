# astrobiology

Multilingual science communication site about astrobiology — built with Astro, Vue, and Tailwind CSS. Deployed at [astrobiologia.com.br](https://astrobiologia.com.br).

## Quickstart

```bash
git clone https://github.com/danielvm-git/astrobiology.git
cd astrobiology
npm install
npm run dev        # → localhost:4321
npm run build      # production build
npm run preview    # preview the build
```

## Localization

Content is served in six locales: `en`, `pt-br`, `es`, `ja`, `nl`, `zh`. English is the default locale and is served unprefixed.
